Projects

radius-admin

A secure web console for FreeRADIUS. It manages 802.1X, MAC authentication bypass, RadSec and switch logins from the browser. Every change is validated before FreeRADIUS sees it and rolled back automatically if the server doesn't come back up.

Python, Flask, PostgreSQL and FreeRADIUS 3.2

Project website Source on GitHub

Ultimate CA Manager

An open-source, self-hosted certificate authority with a web interface. I reported three bugs and contributed the fixes:

  • SAML role mapping ignored the groups sent by the identity provider, so every user got the default role (issue 408).
  • Windows certificate enrollment failed in FIPS mode because SHA-1 request signatures were refused (issue 404).
  • The certificate request page stopped at 20 requests (issue 424).
